# Hello World design exemplar

The Project Welcome Pack reference skill deliberately demonstrates conditional contributor and user profiles, a Markdown template, deterministic rendering, a separate validator, and positive and negative test cases. Its rich structure teaches progressive disclosure: common workflow and contract resources are always relevant, while the audience profile is selected only for its branch.

This is not a mandatory file tree. Most skills should use fewer files. Apply the same reasoning to decide whether a reference changes observable behavior, a script replaces repeated deterministic work, or an asset is truly consumed by an output. Do not copy the example's numbers of scripts, references, fixtures, or tests without an independent need.
